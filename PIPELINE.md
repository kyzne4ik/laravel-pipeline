
# CI/CD Пайплайн

### Шаги пайплайна:
1. **Подготовка окружения:** Установка php, копирование конфига `.env.ci`, установка зависимостей через Composer и выдача прав на папки `storage` и `bootstrap/cache`.
2. **Тесты:** Запуск тестов `php artisan test` с проверкой минимального покрытия кода (Gate) не ниже 50%.
3. **Статический анализ:** Проверка кода с помощью `PHPStan` (Larastan). Если найдены ошибки — пайплайн падает.
4. **Линтинг:** Проверка стандартов кода (PSR-12) с помощью `Laravel Pint` в режиме `--test` (без авто-исправлений).
5. **Симуляция деплоя:** Запускается только при успешном прохождении всех проверок выше. Копирует нужный `.env` файл в зависимости от ветки (`.env.dev`, `.env.uat`, `.env.prod`). Для продуктовой ветки `master` требует обязательного ручного аппрува через GitHub Environments (`reviewer-env`).
